ShiftWake プライバシーポリシー

最終更新日: 2026年10月26日（ver 1.1.0 の仕様に対応）

本プライバシーポリシーは、朝重康生（以下「当方」といいます）が提供するAndroidアプリケーション「ShiftWake」（以下「本アプリ」といいます）における、利用者情報の取り扱いについて定めたものです。

1. 収集する情報と利用目的

本アプリでは、以下の情報を取得・利用する場合があります。

1.1 アラーム設定・スケジュール情報

  • 本アプリは、ユーザーが設定したアラームの日時、ラベル、設定内容をデバイス内のローカルデータベースに保存します。
  • これらの情報は、アラーム機能を正常に動作させるためにのみ使用され、当方のサーバーへ送信されることはありません。

1.2 フィードバック情報

  • ユーザーが本アプリ内の「フィードバック送信」機能を利用した場合、選択されたフィードバックの種類（不具合報告・機能リクエスト・その他）および入力されたテキスト内容が、不具合等の情報とともにFirebaseの解析サービス（Crashlytics）に非致命的エラーの形式で送信されます。この際、OSバージョン、機種名等のデバイス情報が付随して送信されます。
  • フィードバックの送信は、アプリのデータ収集設定がONのときに限り行われます。データ収集がOFFの場合、フィードバックは送信されません。
  • これらの情報は、アプリの品質向上や不具合対応のために利用されます。
  • 氏名、メールアドレス、住所などの個人を特定できる情報は入力しないように、フィードバック画面内で注意喚起しています。

1.3 利用状況データ・クラッシュログ

  • アプリの品質改善および不具合の早期発見のため、Firebase Crashlytics等の解析ツールを使用して、アプリのクラッシュ情報や匿名の利用状況データを収集する場合があります。
  • このデータの収集はユーザーの明示的な同意に基づいて行われ、初回起動時の「データ収集同意ダイアログ」および設定画面からいつでも収集のON/OFFを切り替えることが可能です。同意を撤回した場合、以降のデータ収集は行われません。

1.4 Google カレンダー連携機能（オプション）

本アプリのオプション機能として、ユーザーのGoogleカレンダーとの連携機能を提供しています。当該機能を有効にした場合、以下の情報を取得・処理します:

  • 取得元： カレンダー表示のタイトル、開始日時、更新時刻
  • 利用目的： キーワードに一致する表示の自動化（アラームの自動作成・更新・削除）のため。
  • 外部送信： データはGoogle Calendar APIを経由してGoogleのサーバーとのみ通信を行い、事業者である当方を含む第三者へ送信されることはありません。OAuthスコープは連携機能に最低限必要な calendar.events および calendar.calendarlist.readonly のみです。
  • 保存場所： 取得データは端末内のローカルDB（Room）に保存されます。連携OFF時に収集を停止し、当該時点までに取得したデータは端末内から削除されます。
  • 暗号化： 全ての通信はTLS（HTTPS）で暗号化されます。
  • データの利用範囲： 取得されたデータは、広告、マーケティング、データの共有、人手によるレビュー、AI／機械学習の学習データとして使用されることはありません（Limited Useポリシー取得済み）。

カレンダー連携機能はオプション機能です。使用しない場合、カレンダーデータは一切取得・保存されません。

2. 端末の権限（パーミッション）の使用について

本アプリは、機能の実現に必要な範囲で、以下の端末権限を使用します。

  • 正確なアラームのスケジュール (SCHEDULE_EXACT_ALARM / USE_EXACT_ALARM)
    • 利用目的: ユーザーが指定した正確な時刻にアラームを作動させるために必須となる権限です。
  • 通知の表示 (POST_NOTIFICATIONS)
    • 利用目的: アラームの鳴動時や、次回の予定を通知バーに表示するために使用します。
  • 全画面アラームの表示 (USE_FULL_SCREEN_INTENT)
    • 利用目的: アラームの鳴動時に画面を点灯させ、全画面でアラーム解除画面を表示するために使用します。
  • 端末の起動完了通知 (RECEIVE_BOOT_COMPLETED)
    • 利用目的: 端末の再起動後に、アラーム設定を復元・再スケジュールするために使用します。
  • スリープ状態の保持・音声再生 (WAKE_LOCK / FOREGROUND_SERVICE / FOREGROUND_SERVICE_MEDIA_PLAYBACK)
    • 利用目的: アラームの鳴動中に端末をスリープさせず、アラーム音等を確実に再生し続けるために使用します。
  • バイブレーション (VIBRATE)
    • 利用目的: アラームのバイブレーション動作のために使用します。
  • 他のアプリの上に重ねて表示 (SYSTEM_ALERT_WINDOW)
    • 利用目的: アラームの鳴動時に、他のアプリを使用中であってもアラーム解除画面を正しく表示されるようにするために使用します。
  • カメラ (android.permission.CAMERA)
    • 利用目的: アラーム解除条件の一つである「バーコード/QRスキャン」機能において、コードを読み取るために使用します。
    • 補足: 撮影された映像はコード認識のためにリアルタイムで使用されるのみで、画像データとして保存されたり、外部へ送信されたりすることはありません。
  • ネットワーク通信 (INTERNET / ACCESS_NETWORK_STATE)
    • 利用目的: Google カレンダー連携機能、およびユーザーが同意した場合のみの解析データ（Firebase）の送信に使用します。アラーム設定等のローカルデータの取り扱いには使用しません。

なお、アラーム音の再生は端末が提供するサウンド機能を利用して行われるため、本アプリはストレージの読み込み権限（READ_MEDIA_AUDIO）を要求しません。

3. データの保存と管理

3.1 ローカル保存

アラーム設定、テンプレート、登録済みバーコードなどの主要なデータは、ユーザーの端末内部に保存されます。当方はこれらのデータにアクセスすることはできません。

3.2 データのエクスポート・インポート（JSON形式）

本アプリはデータのバックアップ等の目的で、JSON形式でのエクスポート・インポート機能を提供します。エクスポートされたファイルはユーザー自身の管理下に置かれ、当方がそのファイルの内容に関与することはありません。

4. 第三者への提供

当方は、以下の場合を除き、ユーザーの個人情報を第三者に提供することはありません。

  • ユーザーの同意がある場合
  • 法令に基づき開示が必要な場合
  • 利用状況解析ツール（Firebase Crashlytics等）のプロバイダーに対し、個人を特定できない形式でログ情報が送信される場合（ユーザーがデータ収集に同意した場合のみ）
  • Google カレンダー連携機能が有効な場合に、Google Calendar API を通じて Google のサーバーと必要最低限のデータをやり取りする場合（連携データが当方を経由して第三者に送信されることはありません）

5. 免責事項

本アプリが予期せぬ不具合（端末のバッテリー切れ、OSの強制終了、他のアプリとの競合など）により正常に動作しなかったことに起因する損害（遅刻などによる不利益を含む）について、当方は一切の責任を負いません。重要な予定には、複数の手段で備えることを推奨します。

6. プライバシーポリシーの変更

本アプリのバージョンアップに伴い、本ポリシーを変更する場合があります。重要な変更がある場合は、アプリ内のお知らせ等でユーザーに通知します。
